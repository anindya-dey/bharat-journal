# Submission Tracker

Private tracking for ideas actually sent to a ministry or official channel.
This file is **never referenced from the published site** — see
[SUBMISSION-GUIDELINES.md](./SUBMISSION-GUIDELINES.md) for why, and for the
convention of flipping an idea's public `status` to `"proposed"` once it's
listed here with a real submission date.

Redact personal details before committing anything here if this repo is
ever made more widely shared — for now it tracks channel, date and
reference number only, per the "archive everything" principle in the
guidelines.
