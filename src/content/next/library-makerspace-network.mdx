## Where I saw it

Finland's public libraries, consistently ranked among the world's best,
lend 3D printers, sewing machines and recording equipment alongside books,
and double as community workspaces. The global "Fab Lab" network has shown
the same model works in dozens of countries: a shared space with the tools
a young person or small entrepreneur can't afford alone.

## What's missing

India has a vast network of public libraries and Common Service Centres,
but most are book-only or basic-connectivity-only. The opportunity is to
turn a fraction of them into genuine makerspaces — the kind of access that
currently exists only in a handful of urban startup hubs.

## What India already has

- **A large existing public library network**, run by states and
  municipalities, with physical space already in place.
- **[Common Service Centres](https://www.csc.gov.in/)**, reaching deep into rural India with basic
  digital access.
- **Atal Tinkering Labs**, which already bring maker-education tools into
  schools — the model to extend into public libraries.

## The proposal

1. **Upgrade one library per district** into a makerspace — 3D printers,
   basic electronics, a recording corner and high-speed Wi-Fi — starting
   with existing Atal Tinkering Lab partners.
2. **Open access, not just student access** — so young entrepreneurs and
   self-taught makers outside the school system benefit too.
3. **A shared curriculum of weekend workshops**, run with local ITIs and
   engineering colleges.
4. **Track outcomes publicly** — prototypes built, small businesses
   launched — the way other public-infrastructure programmes report
   progress.

Ask: the Ministry of Culture and MeitY to pilot district-level makerspaces in
existing public libraries, using the Atal Tinkering Lab network as a
template.
